# Ciencia de Datos con Python - Semana 1

## Propósito
Preparar el ambiente de trabajo reproducible y comprender el valor de los datos orientados a la toma de decisiones pedagógicas y productivas.

## Estructura del Proyecto
- `data/raw/`: Almacenamiento de datos originales sin modificar.
- `data/processed/`: Almacenamiento de datos limpios y transformados.
- `notebooks/`: Cuadernos Jupyter para análisis exploratorio.
- `outputs/`: Gráficos, reportes y archivos exportados.
- `docs/`: Documentación del proyecto y guías.
- `scripts/`: Código ejecutable modular en Python.

## Buenas Prácticas
1. **Nunca editar** directamente los archivos ubicados en `data/raw/`.
2. Proteger la privacidad de datos personales y sensibles.
3. Usar siempre rutas relativas mediante la librería `pathlib`.
4. Mantener el entorno virtual `.venv` activado para instalar dependencias.
